# Hermes Route logo

Generated by Anthropic Claude-Opus-5.5 via Claude Code. Rebuild everything with
`python3 ../build_final.py` (needs `fonttools`, `rsvg-convert` and ImageMagick).

## Colors

| Role | On dark | On light |
|---|---|---|
| Teal accent (wing, nodes, "Route") | `#2FD0BC` | `#0B8577` |
| Lines and "Hermes" | `#E6EDF0` | `#1F2933` |
| Background | `#111820` | `#F5F7F8` |

## Variants

Every layout in `symbol/`, `lockup/` and `stacked/` comes in six variants, as SVG and PNG:

| Suffix | Use |
|---|---|
| `on-dark` | Transparent, for dark backgrounds. The primary version. |
| `on-light` | Transparent, for light backgrounds. |
| `white`, `black` | Transparent, single ink, for print, stamps and overlays. |
| `dark-bg`, `light-bg` | Background baked in, with extra padding. |

The wordmark is Fira Sans (SemiBold and Regular, SIL Open Font License), converted
to outlines, so no font is needed to display the files.

## Favicon and app icons

| File | Use |
|---|---|
| `favicon/favicon.svg` | Modern browsers. Simplified cut with solid feathers. |
| `favicon/favicon.ico` | Legacy fallback, holds 16, 32 and 48 px. |
| `favicon/favicon-16.png`, `-32`, `-48` | Individual raster sizes. The 16 px one is simplified further. |
| `favicon/apple-touch-icon.png` | iOS home screen, 180 px, full-bleed square. |
| `favicon/icon-192.png`, `icon-512.png` | PWA manifest icons. |
| `favicon/icon-maskable-512.png` | PWA manifest icon with `"purpose": "maskable"`. |
| `social/og-image.png` | Link previews, 1200x630. |

```html
<link rel="icon" href="/favicon.ico" sizes="48x48">
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">
<meta property="og:image" content="https://YOUR-DOMAIN/og-image.png">
<meta name="theme-color" content="#111820">
```
